# TRACER UI Philosophy

## Project Identity

TRACER is an Explainable AI research platform for academic knowledge discovery.

It is NOT:

- A SaaS landing page
- An AI startup website
- A chatbot interface
- A dashboard-first application

It should feel like a premium academic research workspace.

---

# Design Principles

The interface should communicate:

- Clarity
- Trust
- Curiosity
- Understanding
- Simplicity

Every screen should reduce cognitive load.

---

# Visual Style

The design language should be:

- Editorial
- Minimal
- Spacious
- Elegant
- Modern

Avoid visual clutter.

Whitespace is part of the design.

---

# Layout Philosophy

Large content spacing.

Consistent section padding.

Minimal borders.

Rounded corners.

Subtle shadows only.

Avoid heavy gradients.

Avoid excessive glassmorphism.

Avoid unnecessary animations.

---

# Typography

Large headings.

Comfortable reading width.

Elegant serif headings.

Modern sans-serif body text.

Recommended:

Headings:
- IBM Plex Serif
- Source Serif 4

Body:
- Inter
- Manrope

---

# Color Philosophy

Avoid pure white.

Prefer layered light tones.

Examples:

Hero:
#F8FAFC

Alternate Section:
#EEF4FF

Cards:
#FCFCFD

Navbar/Footer:
#0F172A

Accent:
#4F7CFF

Use only one primary accent color.

---

# Navigation

Minimal.

Only essential links.

Floating rounded navbar.

No unnecessary buttons.

No marketing CTAs.

---

# Hero

No illustrations.

No space theme.

No robots.

No futuristic AI artwork.

The hero should focus on:

Typography

Search

Whitespace

---

# Imagery

Use simple academic illustrations.

Knowledge connections.

Research workflows.

Evidence visualization.

Avoid decorative graphics.

---

# Components

Every component should have one responsibility.

Prefer reusable components.

Avoid deeply nested layouts.

---

# Animations

Use subtle animations.

Fade.

Slide.

Micro interactions.

Avoid flashy motion.

---

# Responsiveness

Mobile-first.

Tablet optimized.

Desktop optimized.

No horizontal scrolling.

---

# Accessibility

Semantic HTML.

Proper heading hierarchy.

Keyboard accessible.

Readable contrast.

---

# Things to Avoid

Do NOT build a generic SaaS website.

Do NOT overuse cards.

Do NOT use fake statistics.

Do NOT add testimonials.

Do NOT add pricing.

Do NOT add blogs.

Do NOT add unnecessary icons.

Do NOT use space, galaxy or astronomy themes.

Do NOT use neon cyberpunk effects.

Do NOT use excessive gradients.

Keep everything purposeful.

---

# Overall Experience

Users should feel like they are entering a modern research workspace where understanding complex knowledge is simple, trustworthy and visually elegant.
